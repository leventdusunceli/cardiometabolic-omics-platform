# Cardiometabolic Crosstalk Omics Platform

A multi-tissue transcriptomics data platform exploring shared biology between type 2 diabetes
and cardiovascular risk, inspired by public research on cardiometabolic disease.

Status: early scaffolding. The full pitch, architecture diagram, and quickstart will land in the
documentation pass once the core pipeline is working end to end. See [CLAUDE.md](CLAUDE.md) for
the detailed project spec and current build progress.
